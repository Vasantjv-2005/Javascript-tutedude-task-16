# Student Records

## Objective

The objective of this project is to create a webpage that displays student records using HTML, CSS, and JavaScript. It also includes a search box to filter student records by name.

## Technologies Used

- HTML
- CSS
- JavaScript
- VS Code

## Features

- Displays student details in card format.
- Shows student name, marks, class, and address.
- Search students by name.
- Updates student records dynamically while typing.
- Uses JavaScript map() and filter() methods.

## Project Structure

```text
Student-Records/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## JavaScript Methods Used

**1. map()**

Used to display all student records in card format.

**2. filter()**

Used to search and display students based on the entered name.

**3. addEventListener()**

Used to detect changes in the search box.

**4. includes()**

Used to check whether the student name matches the search text.

## Student Details

The project contains sample student records with the following details:

- Name
- Marks
- Class
- Address

## How to Run the Project

1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open the index.html file in your browser.
4. All student records will be displayed.
5. Enter a student's name in the search box to filter the records.
